# 13 WS2811灯带实现说明

> 文档状态：专题记录文档
> 适用基线：STM32F429ZET6 + HAL/LL + FreeRTOS(CMSIS-RTOS v2)
> 对应工程：motor_V2.1.1_ws2811
> 说明：本文档说明当前工程的灯带仍按 `WS2811` 口径实现，业务层继续沿用 `ws2811/ws2812` 命名

## 1. 当前实现结论

当前工程灯带底层仍是传统 `WS2811` 风格单线时序：

- `TIM3_ARR_VALUE = 111`
- `DUTY_0 = TIM3_ARR_VALUE * 0.2f`
- `DUTY_1 = TIM3_ARR_VALUE * 0.5f`
- 默认逻辑 LED 数量为 `8`

## 2. 当前实现分层

| 层级 | 文件 | 作用 |
| --- | --- | --- |
| 业务层 | `User/ws2812_task/ws2812_task.c` | 决定颜色与灯效逻辑 |
| 驱动层 | `BSP_Plantform/Bsp_Drivers/ws2812/driver/bsp_ws2812_driver.c/.h` | 负责 bit 编码与像素缓存 |
| 板级层 | `Core/Src/tim.c` | 初始化 `TIM3_CH3 + DMA1_Stream7` |
| 配置层 | `SystemConfig/system_cfg.h` | 定义 LED 数量与四段映射 |

## 3. 当前资源绑定

- 数据输出脚：`PB0`
- 定时器通道：`TIM3_CH3`
- DMA：`DMA1_Stream7`

## 4. 排障建议

- 方向错位优先看 `system_cfg.h` 的四段映射
- 全灭或乱闪优先看 `TIM3_CH3 + DMA1_Stream7 + PB0`
- 颜色异常优先看 `ws2811_set_pixel()` 写入顺序和上层颜色逻辑
