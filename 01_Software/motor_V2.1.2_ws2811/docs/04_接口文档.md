# 04 接口文档

> 文档状态：当前权威文档
> 适用基线：STM32F429ZET6 + HAL/LL + FreeRTOS(CMSIS-RTOS v2)
> 对应工程：motor_V2.1.1_ws2811
> 说明：本文档描述当前工程中对外最重要的协议接口、状态字定义和关键软件接口

## 1. 接口范围

本文档重点覆盖：

- UART1 主机协议
- 关键状态字定义
- 关键共享状态对象
- 主要软件接口与快照接口

本文档不展开讲模块内部实现，内部实现见 `03_模块设计文档.md`。

## 2. UART1 协议概览

### 2.1 基本帧格式

协议定义见：

- `Middlewares/components/host_protocol/host_protocol.h`
- `Middlewares/components/host_protocol/host_protocol.c`

帧格式如下：

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| `H1` | 1 | 固定 `0xA0` |
| `H2` | 1 | 固定 `0x0A` |
| `VER` | 1 | 当前版本 `0x01` |
| `SEQ` | 1 | 帧序号 |
| `TYPE` | 1 | 帧类型 |
| `LEN` | 2 | little-endian，payload 长度 |
| `PAYLOAD` | N | TLV 集合 |
| `CRC16` | 2 | Modbus CRC，覆盖 `VER..PAYLOAD` |

### 2.2 帧类型

定义见 `User/communication_task/host_cmd_defs.h`：

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `UART_TASK_FRAME_TYPE_TELEMETRY` | `0x01` | 设备上报 |
| `UART_TASK_FRAME_TYPE_COMMAND` | `0x81` | 主机下发 |

当前工程没有独立 ACK 帧。

## 3. UART1 命令字段

### 3.1 命令 TLV

| Tag | 字段 | 类型 | 单位/语义 |
| --- | --- | --- | --- |
| `0x01` | 左轮角速度 | `s32` | `mrad/s` |
| `0x02` | 右轮角速度 | `s32` | `mrad/s` |
| `0x03` | 升降高度 | `s32` | `mm` |
| `0x11` | 状态掩码 | `u16` | 与 `0x12` 配对 |
| `0x12` | 状态值 | `u16` | 与 `0x11` 配对 |

### 3.2 命令约束

- `0x01` 和 `0x02` 必须同帧同时出现
- `0x03` 会被限制在 `0 ~ SYSTEM_CFG_JOINT_MAX_TRAVEL_MM`
- `0x11` 与 `0x12` 必须成对出现
- 未知 TLV 不会破坏整帧同步

## 4. UART1 遥测字段

| Tag | 字段 | 类型 | 说明 |
| --- | --- | --- | --- |
| `0x01` | 左轮角速度 | `s32` | 真实反馈，单位 `mrad/s` |
| `0x02` | 右轮角速度 | `s32` | 真实反馈，单位 `mrad/s` |
| `0x03` | 关节位置 | `s32` | 当前关节位置值 |
| `0x04` | 料斗容积 | `u16` | 当前预留 |
| `0x13` | 状态字 | `u16` | 执行状态 |
| `0x14` | 健康字 | `u16` | 健康/故障摘要 |
| `0x15` | 告警信息 | `u16` | 左右轮驱动报警摘要 |
| `0x21` | 电池电量 | `u16` | `x100` 百分比 |

## 5. 状态字定义

定义见 `User/communication_task/host_status_defs.h`。

### 5.1 电机 enable 和 reset 相关位

| 位定义 | 含义 |
| --- | --- |
| `HOST_STATUS_RIGHT_ENABLE_SHIFT = 0` | 右轮 enable 控制位起始 |
| `HOST_STATUS_RIGHT_RESET_BIT = 2` | 右轮 reset 位 |
| `HOST_STATUS_LEFT_ENABLE_SHIFT = 3` | 左轮 enable 控制位起始 |
| `HOST_STATUS_LEFT_RESET_BIT = 5` | 左轮 reset 位 |
| `HOST_STATUS_JOINT_ENABLE_SHIFT = 6` | 关节 enable 控制位起始 |
| `HOST_STATUS_JOINT_RESET_BIT = 8` | 关节 reset 位 |
| `HOST_STATUS_CHARGING_ON_BIT = 14` | 充电状态位 |

### 5.2 reset mask 定义

| 宏 | 含义 |
| --- | --- |
| `ROBOT_RESET_RIGHT_BIT` | 右轮 reset |
| `ROBOT_RESET_LEFT_BIT` | 左轮 reset |
| `ROBOT_RESET_JOINT_BIT` | 关节 reset |

## 6. 关键共享状态对象接口

### 6.1 主机命令 mailbox

定义：`User/communication_task/host_control_cmd.h`

```c
void host_control_cmd_snapshot(host_control_cmd_t *out);
```

用途：

- 给控制层和执行层提供主机命令快照
- `drive_cmd_seq` 和 `lift_cmd_seq` 用于判断是否是切换模式后的新命令

### 6.2 运动意图快照

定义：`User/control_task/robot_motion_cmd.h`

```c
void robot_motion_cmd_snapshot(robot_motion_cmd_t *out);
void robot_motion_cmd_clear_motion(void);
void robot_motion_cmd_set_drive_rpm(int32_t right_rpm, int32_t left_rpm);
void robot_motion_cmd_set_joint_absolute(int32_t joint_abs_pos);
void robot_motion_cmd_set_joint_relative(int32_t joint_rel_pos);
void robot_motion_cmd_clear_joint(void);
```

用途：

- 控制层与执行层之间传递统一运动意图

### 6.3 模式快照接口

定义：`User/control_task/robot_mode_service.h`

```c
void robot_mode_snapshot(ROBOT_MODE_T *out);
```

用途：

- 提供当前主模式和子模式给执行层、灯带、显示等模块

### 6.4 关节回零状态接口

定义：`User/motor_task/motor_task.h`

```c
void motor_task_joint_home_request_set(bool enable);
void motor_task_joint_home_status_snapshot(motor_joint_home_status_t *out);
bool motor_task_joint_is_homed(void);
bool motor_task_joint_home_is_busy(void);
```

用途：

- 控制层查询或触发关节回零相关状态

### 6.5 遥测快照接口

定义：`User/communication_task/telemetry_service.h`

```c
void telemetry_service_snapshot(telemetry_service_snapshot_t *out);
void telemetry_service_diag_maintenance(void);
```

用途：

- 统一聚合对外上报状态

## 7. UART 会话与 freshness 接口

定义：`User/communication_task/uart_task.h`

```c
bool uart_task_start(void);
bool uart_session_is_alive(void);
bool uart_drive_cmd_is_fresh(void);
bool uart_lift_cmd_is_fresh(void);
void uart_task_diag_maintenance(void);
```

语义：

- `uart_session_is_alive()`：最近 1s 内收到过任意有效协议帧
- `uart_drive_cmd_is_fresh()`：最近 1s 内收到过有效驱动命令
- `uart_lift_cmd_is_fresh()`：最近 1s 内收到过有效升降命令

## 8. UART 驱动层接口

定义：`BSP_Plantform/Bsp_Drivers/communication/driver/bsp_uart_driver.h`

主要接口：

```c
void uart_device_init(uint8_t uart_id);
bool uart_device_is_ready(uint8_t uart_id);
uint16_t uart_write(uint8_t uart_id, const uint8_t *buf, uint16_t size);
uint16_t uart_read(uint8_t uart_id, uint8_t *buf, uint16_t size);
void uart_poll_dma_tx(uint8_t uart_id);
void uart_get_diag(uint8_t uart_id, uart_diag_t *out_diag);
void uart_clear_diag(uint8_t uart_id);
```

用途：

- 提供 FIFO + DMA 级别的基础 UART 收发能力
- 提供诊断统计信息给调试使用

## 9. CAN 侧核心接口

### 9.1 队列与恢复接口

## 10. 使用接口时的注意事项

- 主机命令接口是快照式接口，不是命令队列接口
- `robot_motion_cmd_t` 只是意图，不代表一定会被执行
- `status_word` 和 `health_word` 是结果态，不是主机意图态
- 关节相关接口在未回零或 busy 时可能不会产生实际动作
- 现场联调时，优先结合 `uart_session_is_alive()`、`uart_drive_cmd_is_fresh()`、`motor_task_joint_is_homed()` 一起判断
