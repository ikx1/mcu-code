## 5. 当前关键结论

- 启动路径为 `main() -> osKernelInitialize() -> MX_FREERTOS_Init() -> UserAppTask_Init() -> osKernelStart()`
- UART1 主机协议链路基于 `USART1 + DMA2_Stream2/7`
- 显示走 `USART2`，电池走 `USART3`，IBUS 走 `UART4`
- 当前灯带维持 `WS2811` 实现口径，默认逻辑 LED 数为 `8`
- 左右轮命令必须同帧同时下发，单位为 `mrad/s`
- 当前默认允许 `MODE_READY` 保持驱动上电，并允许无遥控器时由上位机接管 `SUB_SLAVE`
