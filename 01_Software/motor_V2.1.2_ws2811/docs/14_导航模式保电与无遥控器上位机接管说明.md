# 14 导航模式保电与无遥控器上位机接管说明

> 文档状态：专题记录文档
> 适用基线：STM32F429ZET6 + HAL/LL + FreeRTOS(CMSIS-RTOS v2)
> 对应工程：motor_V2.1.1_ws2811
> 说明：本文档说明当前工程在导航从控场景下的保电策略，以及无 IBUS 时由上位机接管的边界

## 1. 关键开关

位于 `SystemConfig/system_cfg.h`：

| 宏 | 当前默认值 | 作用 |
| --- | --- | --- |
| `SYSTEM_CFG_READY_KEEP_DRIVE_POWER` | `1` | READY 模式下是否保持驱动轮上电 |
| `SYSTEM_CFG_ALLOW_HOST_SLAVE_WITHOUT_IBUS` | `1` | 无遥控器时是否允许主机接管 |
| `SYSTEM_CFG_HOST_SLAVE_KEEP_DRIVE_POWER` | `1` | `SUB_SLAVE` 下是否保持驱动上电 |

## 2. 生效条件

无遥控器主机接管要成立，至少要满足：

1. UART1 session 有效
2. drive 或 lift 命令 freshness 仍然有效
3. 模式机判定允许进入 `MODE_REMOTE + SUB_SLAVE`

## 3. 安全边界

- 急停优先级最高
- freshness 过期后旧命令不会继续执行
- 执行层仍会根据使能、回零、故障状态拦截动作
- 保电策略不等于一定允许运动
- `SUB_SLAVE` 当前仍会根据左右轮命令差叠加转向灯显示；保电和灯带显示是两条并行链路
