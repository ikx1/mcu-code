# 05 硬件相关文档

> 文档状态：当前权威文档
> 适用基线：STM32F429ZET6 + HAL/LL + FreeRTOS(CMSIS-RTOS v2)
> 对应工程：motor_V2.1.1_ws2811
> 说明：本文档整理当前板级资源映射、外设用途、DMA 与中断关系

## 1. 硬件基线说明

当前工程运行在 `STM32F429ZET6` 上，使用 `HAL + LL` 初始化外设，并通过 `cmsis_os2 + FreeRTOS` 启动任务系统。

## 2. UART 资源映射

| 串口 | 引脚 | 当前用途 |
| --- | --- | --- |
| `USART1` | `PA9/PA10` | UART1 主机协议 |
| `USART2` | `PA2/PA3` | 显示链路 |
| `USART3` | `PB10/PB11` | 电池 Modbus |
| `UART4` | `PA0/PA1` | IBUS 遥控 |
| `USART6` | `PC6/PC7` | 调试输出 |
| `UART8` | `PE1/PE0` | 超声波预留 |

### 2.1 UART1 DMA 资源

| 资源 | 用途 |
| --- | --- |
| `DMA2_Stream2` | `USART1` RX |
| `DMA2_Stream7` | `USART1` TX |

## 3. CAN 与输入输出映射

| 资源 | 引脚 | 说明 |
| --- | --- | --- |
| `CAN1_RX` | `PA11` | CAN 接收 |
| `CAN1_TX` | `PA12` | CAN 发送 |
| 急停 | `PE3` | 高有效 |
| 上限位 | `PE4` | 低有效 |
| 下限位 | `PE5` | 低有效 |
| `limit_c` | `PE6` | 高有效 |
| 超声波 RS485 方向控制 | `PE2` | `RS485_2_RW` |
| 电池 RS485 方向控制 | `PE15` | `RS485_1_RW` |
| `SPI1_CS` | `PA4` | SPI 片选 |

## 4. 灯带硬件资源

| 资源 | 用途 |
| --- | --- |
| `TIM3_CH3` | 灯带 PWM 基础波形 |
| `PB0` | 灯带数据输出 |
| `DMA1_Stream7` | 灯带 DMA 推送 |

当前驱动仍按 `WS2811` 时序口径实现，默认逻辑 LED 数为 `8`。

## 5. 当前板级注意事项

- `UART4` 承担 IBUS，不是显示串口
- `USART2` 当前承担显示链路
- `UART8` 保留给超声波预留链路，默认没有在 `User_Init` 中启用
- 灯带资源固定在 `PB0 + TIM3_CH3 + DMA1_Stream7`
