# 09 时序图_流程图_状态机图

> 文档状态：当前权威文档
> 适用基线：STM32F429ZET6 + HAL/LL + FreeRTOS(CMSIS-RTOS v2)
> 对应工程：motor_V2.1.1_ws2811
> 说明：当前文档使用文字图和 ASCII 图描述关键链路，便于在纯文本环境下快速理解

## 1. 启动流程图

```text
main()
  |
  +-- HAL_Init()
  +-- SystemClock_Config()
  +-- MX_GPIO_Init()
  +-- MX_DMA_Init()
  +-- MX_CAN1_Init()
  +-- MX_USART1_UART_Init()
  +-- MX_UART4_Init()
  +-- MX_USART3_UART_Init()
  +-- MX_USART2_UART_Init()
  +-- MX_TIM3_Init()
  +-- osKernelInitialize()
  +-- MX_FREERTOS_Init()
          |
          +-- create defaultTask
          +-- UserAppTask_Init()
                  |
                  +-- can_queue_init()
                  +-- motor_register()
                  +-- uart_task_start()
                  +-- user_legacy_service_init()
                  +-- create userTask
  +-- osKernelStart()
```

## 2. 主机命令链路

```text
USART1 + DMA2
-> uart_irq_adapter
-> bsp_uart_driver
-> uart_rtos
-> uart_stack
-> host_protocol parser
-> uart_task_apply_command
-> host_control_cmd_t
-> control_task
-> motor_task
```

## 3. 遥控与显示链路

```text
UART4 IRQ -> IBUS -> control_task
USART2 IRQ -> display -> display_handler
USART3 IRQ -> battery modbus -> battery_task
```

## 4. 模式机与执行链路

```text
host_control_cmd / IBUS / input_status
        |
        v
control_task -> robot_motion_cmd
        |
        v
motor_task -> CAN command -> motor drives
        |
        v
telemetry_service -> uart_task telemetry
```

## 5. 灯带链路

```text
robot_mode + battery + drive_feedback
    -> WS2812_Task
    -> ws2811_set_pixel / ws2811_show
    -> TIM3_CH3 + DMA1_Stream7 + PB0
```
