# 06 配置说明文档

> 文档状态：当前权威文档
> 适用基线：STM32F429ZET6 + HAL/LL + FreeRTOS(CMSIS-RTOS v2)
> 对应工程：motor_V2.1.1_ws2811
> 说明：本文档说明当前工程中影响行为的主要配置项及其修改影响

## 1. 配置文件范围

当前工程最重要的配置入口是：

- `SystemConfig/system_cfg.h`
- `BSP_Plantform/Bsp_Drivers/communication/driver/bsp_uart_driver.h`
- `User/communication_task/host_cmd_defs.h`
- `Middlewares/components/host_protocol/host_protocol.h`

## 2. 几何与运动学配置

定义位置：`SystemConfig/system_cfg.h`

- `WHEEL_WIDTH`
- `WHEEL_RADIUS`
- `WHEEL_DIAMETER`
- `WHEEL_PERIMETER`
- `DRIVE_GEAR_RATIO`
- `RPM_TO_ANGULAR(rpm)`
- `ANGULAR_TO_RPM(w)`

## 3. RGB 灯带配置

当前 `system_cfg.h` 默认：

| 宏 | 当前值 | 说明 |
| --- | --- | --- |
| `SYSTEM_CFG_RGB_STRIP_LED_NUM` | `8` | 当前逻辑 LED 总数 |
| `SYSTEM_CFG_RGB_STRIP_SEGMENT_LEFT_FRONT` | `0` | 左前逻辑段 |
| `SYSTEM_CFG_RGB_STRIP_SEGMENT_RIGHT_FRONT` | `1` | 右前逻辑段 |
| `SYSTEM_CFG_RGB_STRIP_SEGMENT_RIGHT_REAR` | `2` | 右后逻辑段 |
| `SYSTEM_CFG_RGB_STRIP_SEGMENT_LEFT_REAR` | `3` | 左后逻辑段 |

当前 `bsp_ws2812_driver.h` 仍按 `WS2811` 口径实现：

- `TIM3_ARR_VALUE = 111`
- `DUTY_0 = TIM3_ARR_VALUE * 0.2f`
- `DUTY_1 = TIM3_ARR_VALUE * 0.5f`
- 没有单独扩大的 `RESET_SLOTS` 配置

## 4. 调试与策略开关

| 宏 | 当前默认值 | 作用 |
| --- | --- | --- |
| `SYSTEM_CFG_ENABLE_DEBUG` | `1` | 调试钩子总开关 |
| `SYSTEM_CFG_READY_KEEP_DRIVE_POWER` | `1` | READY 模式下驱动轮是否保持上电 |
| `SYSTEM_CFG_ALLOW_HOST_SLAVE_WITHOUT_IBUS` | `1` | 无遥控器时是否允许主机接管 |
| `SYSTEM_CFG_HOST_SLAVE_KEEP_DRIVE_POWER` | `1` | `SUB_SLAVE` 下是否保持驱动上电 |
| `SYSTEM_CFG_JOINT_AUTO_HOME_ON_BOOT` | `1` | 上电是否自动回零 |
| `CAN_DIAG_COUNTER_AUTO_CLEAR_MS` | `60000` | CAN 诊断 sticky 窗口稳定多久后重置基线 |

## 5. 关节回零与 UART 配置

- 关节配置与 `motor_V2.1.1_tm16703` 一致，仍由 `SYSTEM_CFG_JOINT_*` 宏控制
- `SYSTEM_CFG_JOINT_AUTO_HOME_ON_BOOT = 0` 时，当前实现会把关节直接视作“已回零”，只建议用于绝对编码器或已确认可跳过回零的机型
- 手动关节点动当前受 `input_status_t.limit_upper/limit_lower` 保护，超限方向会被夹成 `0`
- UART1 FIFO 与 DMA 缓冲当前默认都是 `256`
- 协议常量仍是 `H1=0xA0`、`H2=0x0A`、`UART_PROTO_VER=0x01`、`UART_MAX_PAYLOAD=128`
- CAN 诊断自动清窗当前只重置遥测层基线，不直接清底层 drop / bus-off 生产者计数

## 6. 配置修改建议

- 改 LED 数或段映射后，必须复核四个逻辑位置和转向灯方向
- 改 `SYSTEM_CFG_ENABLE_DEBUG` 前，先确认是否依赖调试路径
- 改 host takeover 相关开关后，必须联调 `SUB_SLAVE` 切入和掉链行为
- 改 `SYSTEM_CFG_JOINT_AUTO_HOME_ON_BOOT` 前，必须确认当前关节是否具备“免回零上电”的硬件前提
