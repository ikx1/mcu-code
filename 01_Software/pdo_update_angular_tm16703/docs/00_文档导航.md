## 4. 快速结论

- 新协议入口只有 `USART1 + DMA2`，对应 `DEV_UART1`。
- 新协议收发均由 `uart_stack + uart_rtos + host_protocol + uart_task` 组成。
- 控制链采用“通信快照 -> 模式机 -> 运动命令 -> 执行层”的单向路径。
- 电机使能、失能、复位、关节回零均收口在 `motor_task.c`。
- 遥测只反映真实状态，不回显主机意图。
- 遥控链路、显示、电池、IBUS 仍通过旧串口兼容路径保留。
