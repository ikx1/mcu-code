# 硬件相关文档

## 1. 硬件平台概览

当前工程面向基于 `STM32F429` 的控制板，主要控制对象包括：

- 右驱动轮电机
- 左驱动轮电机
- 升降关节电机
- 上位机 UART1
- 遥控接收机 IBUS
- 电池 Modbus 从机
- 显示终端
- WS2812 指示灯

## 5. DMA 与中断映射

### 5.1 UART1 DMA

| 通道 | 配置 | 作用 |
| --- | --- | --- |
| `DMA2_Stream2 Channel4` | 外设到内存 | `USART1_RX` |
| `DMA2_Stream7 Channel4` | 内存到外设 | `USART1_TX` |

UART1 中断事件：

- `USART1 IDLE`
- `DMA2_Stream2 HT/TC`
- `DMA2_Stream7 TC`

这些事件通过 `uart_irq_adapter.c` 转换为驱动层事件。

### 5.2 CAN 中断

当前启用：

- `CAN1_TX_IRQn`
- `CAN1_RX0_IRQn`

CAN 恢复逻辑中保留了 `CAN1_SCE_IRQn` 的恢复与状态保存接口，但现工程默认未显式启用该中断。

## 6. 板级连接关系

```text
上位机 <-> USART1(DMA) <-> 新协议链路
显示屏 <-> USART2 <-> legacy display
电池BMS <-> USART3(RS485_1_RW) <-> Modbus
遥控接收机 <-> UART4 <-> IBUS
电机驱动器 x3 <-> CAN1
WS2812 <-> TIM3_CH3(PB0)
限位/急停 <-> GPIOE 输入
```

## 7. 硬件行为约束

### 7.1 急停和限位

- 急停由 `ScramTask` 每 10ms 采样
- 急停有效时，控制层切换到 `MODE_EMERGENCY`
- 关节手动控制和回零都会参考上下限位输入

### 7.2 RS485 方向控制

- 电池链路写数据前将 `RS485_1_RW` 拉高，发送完成后拉低
- 超声波预留链路使用 `RS485_2_RW`

### 7.3 关节回零依赖

关节回零依赖以下硬件条件：

- 关节电机可正常上电并进入 `JOINT_ENABLE`
- 下限位信号 `limit_lower` 可被正确触发
- 总线通信无异常

若以上任一条件不满足，回零可能进入 `FAULT`。

## 8. 当前未启用或保留资源

以下资源在工程中存在，但默认未在 `main()` 中启用：

- `SPI1`
- `SPI2`
- `IWDG`
- `USART6`
- `UART8`

这意味着对应功能若要启用，需要同时补齐初始化、任务、驱动和联调用例。
# 更新说明（2026-03-13）

本页历史内容仍保留了部分旧板卡描述，当前硬件请以本节为准。

## 当前板级基线

- MCU：`STM32F103VET6`
- 上位机链路：`USART1(PA9/PA10) + DMA1_Channel4/5`
- 电池 Modbus：`USART3(PB10/PB11)`，方向脚 `PE15`
- 超声波预留链路：`USART2(PA2/PA3)`，方向脚 `PE14`
- 显示：`UART4(PC10/PC11)`
- IBUS：`UART5(PC12/PD2)`
- WS2811/WS2812：`TIM3_CH2(PA7) + DMA1_Channel3`
- 继电器：`PB0=relay1`，`PB1=relay2`
- 急停/限位：`PE7` 高有效，`PE8/PE9` 低有效

## 当前 WS2811 稳定方案

- `TIM3_ARR_VALUE = 89`
- 整帧 DMA 发送
- 缓冲尾部追加 `64` 个 reset slots
- 不再切换 `PA7` 为普通 GPIO 拉低

## 当前联调前必须核对的实物点

1. `PE7/PE8/PE9` 的接线与极性。
2. `PB0/PB1` 是否确实接到继电器 1/2。
3. `PA7` 是否直接连到灯带首颗 `DIN`。
4. `PE15/PE14` 是否分别接到电池和超声波的 `RS485` 方向控制。
