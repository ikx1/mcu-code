本目录文档以当前 `pdo_update_angular_tm16703` 工程为准，当前硬件基线已经切换到 `STM32F103VET6 + StdPeriph + FreeRTOS`，不再沿用 `F429` 时代的板级资源描述。

当前实现的关键结论：

- UART1 通信协议仅使用 `Telemetry(0x01)` 和 `Command(0x81)` 两类帧，不发送 `ACK(0x02)`。
- 下发与上传的 `0x01 / 0x02` 都表示左右轮角速度，单位均为 `mrad/s`。
- `0x03` 表示升降目标或升降反馈，单位为 `mm`。
- 驱动命令要求 `0x01` 和 `0x02` 同帧同时出现，单轮命令无效。
- UART1 上传与接收处理频率为 `100Hz`，控制链和反馈链也已对齐到 `100Hz`。
- 会话超时、底盘命令新鲜度、升降命令新鲜度统一为 `1s`。
- `MODE_READY` 当前默认允许驱动轮保持上电，`SYSTEM_CFG_READY_KEEP_DRIVE_POWER=1`。
- 当前默认开启 `SYSTEM_CFG_ALLOW_HOST_SLAVE_WITHOUT_IBUS=1`，`IBUS` 未连接时只要上位机持续发送新鲜的 `drive/lift` 命令，模式机会自动切到 `MODE_REMOTE + SUB_SLAVE`。
- 当前默认开启 `SYSTEM_CFG_HOST_SLAVE_KEEP_DRIVE_POWER=1`，进入 `MODE_REMOTE + SUB_SLAVE` 后驱动轮保持上电，不会因为上位机会话暂时中断自动掉电；急停和主机会话有效时的显式 disable 仍然优先。
- WS2812 当前实现为：READY 紫灯、急停红灯闪烁、充电红灯/满电绿灯、遥控转向时按左右侧分段闪烁。
- RGB 灯条按 `4` 个逻辑位置段管理，默认映射为 `左前、右前、右后、左后`；如果灯条安装顺序改变，只需要改 `system_cfg.h` 里的 `SYSTEM_CFG_RGB_STRIP_SEGMENT_*` 宏。
- `bucket_volume(0x04)` 当前没有真实传感器源，未实现时不上报该 TLV。

当前板级迁移已确认的关键映射：

- `PE7` 为急停输入，高电平有效。
- `PE8` 为上限位，低电平有效；`PE9` 为下限位，低电平有效。
- `PB0` 为 `relay1`，`PB1` 为 `relay2`。
- 电池 `RS485` 方向脚为 `PE15`，超声波 `RS485` 方向脚为 `PE14`。
- 当前 RGB 灯带已切换为 `SM16703P/TM16703`，底层仍复用 `TIM3_CH2(PA7) + DMA1_Channel3` 单线发送；业务层保留历史 `ws2811/ws2812` 接口，时序按 `SM16703P` 的 `800Kbps + Trst>=200us` 参数运行。
