# 测试文档

## 1. 测试目标

验证当前 `motor_V2.0.3` 工程满足以下目标：

- 协议编解码正确
- 模式切换正确
- 上位机控制链正确
- 电机执行与保护逻辑正确
- 遥测反映真实状态
- 异常条件下系统进入安全行为

## 2. 测试现状

当前仓库未内置自动化测试框架，也没有 `tests/` 目录。现阶段建议采用以下 3 类测试组合：

- 主机侧单元测试
- 板级集成测试
- 现场联调回归测试

## 4. 重点测试场景

### 4.1 UART1 协议链测试

建议使用固定样例帧验证：

- 空载遥测帧
- 完整 drive 命令帧
- 完整 lift 命令帧
- 完整 power-policy 命令帧
- 混合命令帧

### 4.2 安全测试

必须覆盖：

- 会话超时
- 急停触发
- 电机报警
- CAN bus-off 恢复
- 回零失败
- 兼容链路掉线

### 4.3 边界测试

必须覆盖：

- 左右轮最大/最小角速度
- 升降高度 `0` 和 `230`
- 连续模式切换
- 高频率重复命令
- 大量未知 TLV

## 5. 手工测试建议流程

### 5.1 基础通电测试

1. 上电后确认无异常复位
2. 确认 WS2812 在非急停、非充电状态下进入 READY 紫灯
3. 确认 UART1 周期上报存在
4. 确认 CAN1 总线无异常计数增长

### 5.2 遥控模式测试

1. 接入 IBUS
2. 验证 `MODE_REMOTE`
3. 验证 `SUB_STOP / SUB_MANUAL / SUB_SLAVE / SUB_MOTOR_CTRL` 切换
4. 验证高速/低速档切换

### 5.3 主机从机模式测试

1. 切到 `SUB_SLAVE`
2. 发送完整双轮命令
3. 观察 `robot_motion_cmd_snapshot()`
4. 检查底盘是否按预期转动
5. 停止发送命令，验证 1s 后自动归零

### 5.4 WS2812 灯效测试

1. 在 `MODE_READY` 且未充电时，确认整条灯带为紫灯。
2. 触发急停，确认整条灯带以固定节拍红灯闪烁。
3. 接入充电且电池通信正常时，确认整条灯带显示红灯；当电量大于 `90%` 时切换为绿灯。
4. 进入 `MODE_REMOTE + SUB_MANUAL` 或 `MODE_REMOTE + SUB_SLAVE`，给出明确左转/右转指令，确认转向灯按当前逻辑位置映射工作：左转点亮左前和左后，右转点亮右前和右后。
5. 若现场灯条安装方向与默认顺序不一致，修改 `SYSTEM_CFG_RGB_STRIP_SEGMENT_*` 宏后重新验证左转/右转位置，确认逻辑位置与实物位置一致。

### 5.5 关节回零与位置测试

1. 切到回零触发子模式
2. 观察回零状态机进入 `WAIT_MOTOR -> SEEK_LOWER -> SETTLE -> ZERO -> DONE`
3. 回零完成后发送升降绝对位置命令
4. 验证关节反馈位置随命令变化

## 6. 验收标准

项目验收至少满足以下条件：

- 上位机 UART1 命令可稳定收发
- drive / lift / power-policy 语义正确
- 急停、超时、回零故障等安全逻辑正确
- 遥测可反映真实底盘、关节、电池、健康状态
- 旧串口兼容链路不受新协议影响
