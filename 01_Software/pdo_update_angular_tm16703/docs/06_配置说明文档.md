# 配置说明文档

## 1. 配置总览

本项目的配置分为 4 类：

- 系统级编译开关
- 协议与通信参数
- 控制与执行参数
- 诊断与缓冲区参数

主要配置文件：

- `SystemConfig/system_cfg.h`
- `User/communication_task/host_cmd_defs.h`
- `User/communication_task/uart_task.c`
- `User/control_task/control_task.c`
- `User/motor_task/motor_task.c`
- `BSP_Plantform/Bsp_Drivers/communication/driver/bsp_uart_driver.h`

## 2. 系统级编译开关

### 2.1 `system_cfg.h`

| 宏 | 默认值 | 说明 |
| --- | --- | --- |
| `SYSTEM_CFG_ENABLE_DEBUG` | `0` | 是否开启 `DEBUG` 条件编译 |
| `SYSTEM_CFG_READY_KEEP_DRIVE_POWER` | `0` | `MODE_READY` 是否允许驱动保持带电 |
| `CAN_DIAG_RX_DEPTH_WARN` | `24` | CAN 接收深度预警阈值 |
| `CAN_DIAG_RX_DROP_HOLD_MS` | `3000` | RX 丢帧事件保持时间 |
| `CAN_DIAG_BUSOFF_HOLD_MS` | `5000` | BUS-OFF 事件保持时间 |
| `CAN_DIAG_RECOVER_HOLD_MS` | `5000` | 恢复失败事件保持时间 |
| `CAN_DIAG_COUNTER_AUTO_CLEAR_MS` | `60000` | CAN 诊断计数自动清理周期 |

建议：

- 生产版本保持 `SYSTEM_CFG_ENABLE_DEBUG=0`
- 若现场需要 READY 带电待命，必须明确开启 `SYSTEM_CFG_READY_KEEP_DRIVE_POWER=1`

### 3.2 字节序配置

| 宏 | 默认值 | 说明 |
| --- | --- | --- |
| `UART_TASK_COMMAND_BYTE_ORDER` | `UART_TASK_BYTE_ORDER_LITTLE` | 下行命令字节序 |

说明：

- 当前默认命令字节序是 Little Endian

## 7. 构建与集成配置

### 7.1 工程集成

- 主工程文件：`MDK-ARM/Car_Control.uvprojx`
- 若迁移到其它构建系统，至少要包含：
  - `Core/`

  - `MCU_Platform/`
  - `Middlewares/components/`
  - `Drivers/`
  - `Middlewares/Third_Party/FreeRTOS/`

### 7.2 必须同步检查的配置点

修改以下内容后，必须同步更新协议文档和联调脚本：

- Tag 定义
- 字节序
- 超时阈值
- `MODE_READY` 带电策略
- 电机限幅
- 回零流程参数

## 8. 调参建议

- 调整轮速参数前，先确认机械减速比 `DRIVE_GEAR_RATIO`
- 修改回零超时前，先确认关节实际行程和限位响应时间
- 扩大 UART 缓冲区前，先确认 RAM 预算和任务调度延迟
- 放宽超时前，先评估联调链路抖动与安全要求

## 9. 配置变更流程建议

1. 修改宏定义或常量
2. 更新对应文档
3. 完成协议/功能回归测试
4. 联调确认主机端与下位机端配置一致

## 10. 接手时最需要优先确认的配置

如果是新接手人员，建议先确认下面 8 项，不然很容易在错误假设上调试半天。

| 检查项 | 默认值 | 影响 |
| --- | --- | --- |
| `SYSTEM_CFG_READY_KEEP_DRIVE_POWER` | `0` | READY 下驱动轮默认不上电 |
| `UART_TASK_COMMAND_BYTE_ORDER` | Little Endian | 主机命令字节序必须一致 |
| UART1 波特率 | `115200` | 主机串口参数必须匹配 |
| `UART_TASK_SESSION_TIMEOUT_MS` | `1000ms` | 1s 不来帧会清空命令数据面 |
| `UART_TASK_DRIVE_CMD_TIMEOUT_MS` | `1000ms` | drive 过期后会自动归零 |
| `UART_TASK_LIFT_CMD_TIMEOUT_MS` | `1000ms` | lift 过期后会自动清空 |
| `SYSTEM_CFG_JOINT_HOME_TIMEOUT_MS` | `约39000ms` | 由最大行程、估算速度和裕量自动计算 |
| `DRIVE_GEAR_RATIO` | `10.0` | 轮角速度与电机 rpm 转换关系 |

## 11. 配置变更后的验证清单

### 11.1 改协议相关配置后

至少验证：

- CRC 正确
- 命令能被 `uart_task_apply_command()` 解析
- 遥测字段长度和字节序正确
- 主机端与下位机端解释一致

### 11.2 改模式或功率策略后

至少验证：

- READY / REMOTE / EMERGENCY 模式切换
- `SUB_SLAVE` 下 host 命令是否仍按预期生效
- 电机 enable/disable 是否符合安全预期

### 11.3 改回零参数后

至少验证：

- 正常回零
- 触发下限位时流程是否进入 `SETTLE -> ZERO`
- 机械未触底时是否按超时进入 `FAULT`

## 12. 推荐不要轻易改动的配置

以下配置不是不能改，而是改动后联动面较大，必须有明确理由：

- `UART_MAX_PAYLOAD`
- `UART_DMA_RX_BUF_SIZE`
- `UART_DMA_TX_BUF_SIZE`
- `SYSTEM_CFG_READY_KEEP_DRIVE_POWER`
- `DRIVE_GEAR_RATIO`
- GPIO 限位极性

原因：

- 会同时影响协议、调度、RAM 占用、主机解释或机械安全语义。

## 13. 当前补充说明（2026-03-13）

以下内容优先于上文旧结论。

### 13.1 导航模式与驱动上电相关宏

- `SYSTEM_CFG_READY_KEEP_DRIVE_POWER = 1`
- `SYSTEM_CFG_ALLOW_HOST_SLAVE_WITHOUT_IBUS = 1`
- `SYSTEM_CFG_HOST_SLAVE_KEEP_DRIVE_POWER = 1`
- `SYSTEM_CFG_RGB_STRIP_LED_NUM = 8u`
- `SYSTEM_CFG_RGB_STRIP_SEGMENT_LEFT_FRONT = 0u`
- `SYSTEM_CFG_RGB_STRIP_SEGMENT_RIGHT_FRONT = 1u`
- `SYSTEM_CFG_RGB_STRIP_SEGMENT_RIGHT_REAR = 2u`
- `SYSTEM_CFG_RGB_STRIP_SEGMENT_LEFT_REAR = 3u`

### 13.2 当前行为

- `MODE_READY` 当前允许驱动轮保持上电。
- `MODE_REMOTE + SUB_SLAVE` 当前进入后保持驱动轮上电，不再因上位机会话暂时中断自动掉电失能。
- 无遥控器时，只要上位机持续发送新鲜的 `drive/lift` 命令，模式机会自动切到 `MODE_REMOTE + SUB_SLAVE`。
- 急停仍然最高优先级；只有在主机会话仍有效且 `power-policy` 明确下发 disable 时，才会立刻失能。
- RGB 灯条当前按 `4` 个逻辑位置段驱动，默认映射为 `左前、右前、右后、左后`；若灯条反装，可改为 `3/2/1/0` 这组段号。

- `UART_TASK_DRIVE_CMD_TIMEOUT_MS = 1000`

- 急停优先级不变，命令超时后仍会回到 `MODE_READY`
