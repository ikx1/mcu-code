# 项目概述文档

## 1. 项目定位

`motor_V2.0.3` 是一套运行在 `STM32F429` 平台上的运动控制与通信软件，使用 `FreeRTOS` 组织多任务调度，面向一台具备双驱底盘、升降关节、遥控输入、上位机串口控制、电池管理和状态显示能力的设备。

本项目的核心目标是：

- 通过 UART1 接收上位机命令并上报真实遥测
- 通过 CAN1 控制右轮、左轮、升降关节 3 个电机节点
- 在遥控、本地安全逻辑和上位机从机模式之间进行仲裁
- 在急停、链路失效、回零未完成等情况下维持安全行为
- 保留显示、电池、IBUS 等历史串口链路的兼容能力

## 2. 运行环境

| 项目项 | 内容 |
| --- | --- |
| MCU | `STM32F429` |
| RTOS | `FreeRTOS` |
| IDE/工程文件 | `MDK-ARM/Car_Control.uvprojx` |
| 主控制总线 | `CAN1` |
| 新协议链路 | `USART1 + DMA` |
| 兼容链路 | `USART2` 显示、`USART3` 电池/Modbus、`UART4` IBUS |
| 灯效输出 | `TIM3 CH3 + DMA` 驱动 WS2812 |

## 3. 功能范围

### 3.1 已实现功能

- UART1 TLV 协议收发
- 上位机底盘双轮角速度命令接收
- 上位机升降目标高度命令接收
- 上位机电机 power/reset 策略接收
- 遥控模式机与子模式切换
- 双驱电机使能、失能、复位、速度下发
- 升降关节使能、失能、复位、回零、位置下发
- 电池电量、急停、IBUS、CAN 诊断聚合上报
- WS2812 状态/转向灯效

### 3.2 当前未接入真实执行器/传感器的能力

- `bucket_volume(0x04)` 水量传感器
- 喷淋执行器
- 排水执行器
- 夹爪执行器
- 超声波链路

这些能力在当前版本中只能视作协议保留位或预留接口，不能当作已交付能力。

## 4. 软件入口与启动方式

启动链路如下：

1. `main()` 完成 HAL、时钟、GPIO、DMA、CAN、USART、TIM 初始化
2. `MX_FREERTOS_Init()` 创建 `defaultTask`
3. `UserAppTask_Init()` 初始化 CAN、电机注册、新旧串口服务
4. `user_app_task_entry()` 创建控制、执行、反馈、兼容服务等业务任务
5. 调度器接管后进入稳态运行

## 5. 核心运行模式

系统主模式：

- `MODE_READY`
- `MODE_EMERGENCY`
- `MODE_REMOTE`
- `MODE_DISPLAY`

系统子模式：

- `SUB_STOP`
- `SUB_MANUAL`
- `SUB_SLAVE`
- `SUB_CHARGE`
- `SUB_MOTOR_CTRL`
- `SUB_MOTOR_ERR_CLR`

当前对上位机最关键的模式约束是：

- 只有 `MODE_REMOTE + SUB_SLAVE` 下，上位机底盘命令才会真正进入控制链
- 升降绝对位置控制必须在关节回零完成之后才能执行
- `MODE_READY` 默认是无力矩安全待机

### 5.1 WS2812 状态灯规则

- `MODE_EMERGENCY` 下整条灯带红灯闪烁，优先级最高。
- 除急停外，电池通信正常且检测到正在充电时，整条灯带显示充电状态：默认红灯，电量 `> 90%` 时切换为绿灯。
- `MODE_READY` 下整条灯带显示紫灯。
- `MODE_REMOTE + SUB_SLAVE` 下整条灯带显示蓝灯，其余 `MODE_REMOTE` 子模式显示绿灯。
- 转向灯在 `MODE_REMOTE + SUB_MANUAL/SUB_SLAVE` 下按四段逻辑位置叠加闪烁；默认映射为 `左前、右前、右后、左后`，左转点亮左前和左后，右转点亮右前和右后。若灯条安装顺序改变，可通过 `system_cfg.h` 中的 `SYSTEM_CFG_RGB_STRIP_SEGMENT_*` 宏调整。

## 7. 关键设计原则

- 通信层、控制层、执行层、遥测层职责分离
- 共享状态必须有唯一所有者
- 新协议命令是“最近一次有效快照”，不是消息队列
- 遥测必须反映真实设备状态
- 链路超时、急停、回零故障优先于普通控制命令

## 8. 非目标与边界

当前项目不覆盖以下能力：

- PC 端上位机软件
- 云端日志、远程升级、参数持久化
- 自动化单元测试框架
- 双路新协议 UART 并行接入
- 复杂权限/认证机制

# 更新说明（2026-03-13）

当前工程已迁移到 `STM32F103VET6 + StdPeriph + FreeRTOS`，本页以下若出现旧版 `F429`、`TIM3_CH3(PB0)`、`UART4=IBUS` 等描述，均以上述新基线和 [13_F103VET6迁移与板级适配记录](./13_F103VET6迁移与板级适配记录.md) 为准。

当前已确认的核心结论：

- `USART1 + DMA1_Channel4/5` 为上位机主协议链路。
- `UART4(PC10/PC11)` 当前用于显示，`UART5(PC12/PD2)` 当前用于 IBUS。
- `WS2811/WS2812` 当前使用 `TIM3_CH2(PA7) + DMA1_Channel3`。
- `PE7` 急停高有效，`PE8/PE9` 分别为上限位/下限位且均为低有效。
- `PB0/PB1` 当前分别为 `relay1/relay2`。
