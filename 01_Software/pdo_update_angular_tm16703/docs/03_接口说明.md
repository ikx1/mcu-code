# 03 接口说明

## 1. UART1 协议接口

### 1.1 帧格式

```text
H1 H2 VER SEQ TYPE LEN_L LEN_H PAYLOAD CRC_H CRC_L
```

说明：

- `H1 = 0xA0`
- `H2 = 0x0A`
- `VER = 0x01`
- `SEQ` 为单字节序号
- `TYPE = 0x01` 表示遥测，`0x81` 表示命令
- `LEN` 为 Little Endian，表示 `PAYLOAD` 长度
- `CRC16` 覆盖范围为 `VER..PAYLOAD`

### 1.2 下发 TLV

| Tag | 类型 | 单位 | 含义 | 备注 |
| --- | --- | --- | --- | --- |
| `0x01` | `int32` | `mrad/s` | 左轮角速度命令 | 必须与 `0x02` 同帧出现 |
| `0x02` | `int32` | `mrad/s` | 右轮角速度命令 | 必须与 `0x01` 同帧出现 |
| `0x03` | `int32` | `mm` | 升降目标高度 | 独立生效 |
| `0x11` | `uint16` | - | `status_mask` | 必须与 `0x12` 同帧出现 |
| `0x12` | `uint16` | - | `status_value` | 必须与 `0x11` 同帧出现 |

约束：

- `0x01/0x02` 任一缺失，drive 域丢弃。
- `0x11/0x12` 任一缺失，power-policy 域丢弃。
- 已识别字段长度错误或数值越界时，仅丢弃所属域。

### 1.3 上行 TLV

| Tag | 类型 | 单位 | 含义 | 当前实现 |
| --- | --- | --- | --- | --- |
| `0x01` | `int32` | `mrad/s` | 左轮真实角速度 | 已实现 |
| `0x02` | `int32` | `mrad/s` | 右轮真实角速度 | 已实现 |
| `0x03` | `int32` | `mm` | 升降位置反馈 | 已实现 |
| `0x04` | `uint16` | `mL` | 水箱余量 | 预留，当前无真实数据源时不上报 |
| `0x13` | `uint16` | - | `status_word` | 已实现 |
| `0x14` | `uint16` | - | `health_word` | 已实现 |
| `0x15` | `uint16` | - | `alarm_info` | 已实现 |
| `0x21` | `uint16` | `0.01%` | 电池电量 | 已实现 |

### 1.4 状态位定义

#### `status_value` / `status_word`

| 位段 | 含义 |
| --- | --- |
| bit0..1 | 右轮电机 power command |
| bit2 | 右轮复位 |
| bit3..4 | 左轮电机 power command |
| bit5 | 左轮复位 |
| bit6..7 | 关节电机 power command |
| bit8 | 关节复位 |
| bit12 | spray on |
| bit13 | drain on |
| bit14 | charging on |
| bit15 | gripper closed |

说明：

- `power command` 编码：`0=none, 1=enable, 2=disable`
- 当前执行层只消费驱动轮和关节的 power/reset 位
- spray / drain / charging / gripper 当前仅保留协议位定义，不代表对应执行器已接入

## 2. 软件接口

### 2.1 UART 任务接口

头文件：`User/communication_task/uart_task.h`

```c
bool uart_task_start(void);
bool uart_session_is_alive(void);
bool uart_drive_cmd_is_fresh(void);
bool uart_lift_cmd_is_fresh(void);
void uart_task_diag_maintenance(void);
```

说明：

- `uart_task_start()`：启动 UART1 协议服务
- `uart_session_is_alive()`：最近 `1s` 是否收到任意有效协议帧
- `uart_drive_cmd_is_fresh()`：最近 `1s` 是否收到完整 drive 命令
- `uart_lift_cmd_is_fresh()`：最近 `1s` 是否收到合法 lift 命令
- `uart_task_diag_maintenance()`：会话超时维护和诊断维护入口

### 2.2 host mailbox 接口

头文件：`User/communication_task/host_control_cmd.h`

```c
typedef struct
{
    int32_t left_wheel_angular_mrad_s;
    int32_t right_wheel_angular_mrad_s;
    uint32_t drive_cmd_seq;
    int32_t z_lift_mm;
    uint32_t lift_cmd_seq;
    uint8_t motor_reset_mask;
    host_motor_power_cmd_t right_motor_power_cmd;
    host_motor_power_cmd_t left_motor_power_cmd;
    host_motor_power_cmd_t joint_motor_power_cmd;
} host_control_cmd_t;

void host_control_cmd_snapshot(host_control_cmd_t *out);
```

说明：

- mailbox 只允许通信层写
- 其它层通过 `snapshot` 获取一致性快照
- `drive_cmd_seq / lift_cmd_seq` 用于区分“进入从机模式前”和“进入后”的新命令

### 2.3 模式服务接口

头文件：`User/control_task/robot_mode_service.h`

```c
typedef struct
{
    ROBOT_MODE_MAIN robot_mode_main;
    ROBOT_MODE_SUB robot_mode_sub;
    ROBOT_SPEED_LEVEL robot_speed_level;
} ROBOT_MODE_T;

void robot_mode_snapshot(ROBOT_MODE_T *out);
```

说明：

- 提供只读模式快照
- 供执行层、显示层、其它辅助模块读取

### 2.4 运动命令接口

头文件：`User/control_task/robot_motion_cmd.h`

```c
typedef struct
{
    int32_t right_rpm;
    int32_t left_rpm;
    robot_joint_cmd_type_t joint_cmd_type;
    int32_t joint_cmd_value;
} robot_motion_cmd_t;

void robot_motion_cmd_snapshot(robot_motion_cmd_t *out);
void robot_motion_cmd_clear_motion(void);
void robot_motion_cmd_set_drive_rpm(int32_t right_rpm, int32_t left_rpm);
void robot_motion_cmd_set_joint_absolute(int32_t joint_abs_pos);
void robot_motion_cmd_set_joint_relative(int32_t joint_rel_pos);
void robot_motion_cmd_clear_joint(void);
```

说明：

- 控制层写，执行层读
- 不承载 power/reset 语义
- 关节命令支持绝对位置和相对位置两类

### 2.5 电机任务接口

头文件：`User/motor_task/motor_task.h`

```c
void motor_task_joint_home_request_set(bool enable);
void motor_task_joint_home_status_snapshot(motor_joint_home_status_t *out);
bool motor_task_joint_is_homed(void);
bool motor_task_joint_home_is_busy(void);

void Can_Analy_Task(void *pvParameters);
void Motor_Task(void *pvParameters);
void Robot_Speed_Task(void *pvParameters);
```

说明：

- `motor_task_joint_home_request_set()`：控制层发起或取消回零请求
- `motor_task_joint_home_status_snapshot()`：获取回零状态
- `motor_task_joint_is_homed()`：判断回零是否完成
- `motor_task_joint_home_is_busy()`：判断回零状态机是否占用关节所有权

### 2.6 底盘反馈接口

头文件：`User/motor_task/drive_feedback_service.h`

```c
typedef struct
{
    int32_t left_wheel_angular_mrad_s;
    int32_t right_wheel_angular_mrad_s;
} drive_feedback_t;

void drive_feedback_snapshot(drive_feedback_t *out);
```

说明：

- 对外提供左右轮真实角速度
- 供 `telemetry_service` 读取

### 2.7 遥测聚合接口

头文件：`User/communication_task/telemetry_service.h`

```c
typedef struct
{
    int32_t left_wheel_angular_mrad_s;
    int32_t right_wheel_angular_mrad_s;
    int32_t z_lift_mm;
    uint16_t status_word;
    uint16_t health_word;
    uint16_t alarm_info;
    uint16_t batt_soc_x100;
    uint16_t bucket_volume_ml;
    uint8_t bucket_volume_valid;
} telemetry_service_snapshot_t;

void telemetry_service_snapshot(telemetry_service_snapshot_t *out);
void telemetry_service_diag_maintenance(void);
```

说明：

- `telemetry_service_snapshot()` 返回真实上传快照
- `bucket_volume_valid == 0` 时，UART1 不发送 `0x04`

## 3. 模块边界约束

### 3.1 禁止跨层行为

以下行为禁止：

- 控制层直接调用电机驱动接口
- 通信层直接写运动命令快照
- 执行层改写 host mailbox
- 上传层回显 host 命令伪装成真实状态

### 3.2 合法调用方向

推荐方向：

```text
uart_task -> host mailbox
control_task -> robot_motion_cmd
motor_task -> drive_feedback
telemetry_service -> telemetry snapshot
```

## 4. 当前协议差异说明

与历史联调文档相比，当前实现明确采用：

- 左右轮角速度，而不是 `v_linear / w_angular`
- 无 ACK
- 100Hz 上传与 100Hz 处理
- 1s 超时保护
